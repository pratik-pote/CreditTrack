# CreditTrack
CreditBook is a simple and open-source credit management app that helps users track money they have given or need to receive. Users can add people, record credit amounts, track payments, and manage their balances. Future features will include user authentication, a real database, and secure user-specific data.


CreditBook 📒

An open-source credit book application built with the goal of learning, collaborating, and growing together.

CreditBook helps users keep track of money given and received from different people.

The project is currently in development, and contributors are welcome! 🚀

🎯 Project Goal

The main goal of CreditBook is to build a useful, simple, and beginner-friendly open-source project where developers can learn, contribute, and collaborate.

I am especially looking for people who want to help improve the project and share their knowledge.

🚀 Current Features
Add credit records
Track people and balances
Record payments
View pending amounts
Simple dashboard
